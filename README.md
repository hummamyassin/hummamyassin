# 💫 About Me:
Hi, I’m Hummam Yassin 👋

**Computer Engineering Graduate | Software & Cloud Enthusiast**

I’m based in Amman, Jordan, and interested in cloud infrastructure, networking, and software development. My cloud training gave me hands-on experience with Linux VMs, SSH, deployment, and troubleshooting.

- **FISST** — I’m building a bilingual SaaS app for managing tenders and quotations with Next.js, TypeScript, and Supabase.
- **VAELORA** — I built and deployed a web app that uses live weather and location data to help people plan outdoor activities in Jordan.
- **Smart Environmental Monitoring System** — For my capstone, I helped build an ESP32-C6 and Firebase system and developed its real-time monitoring dashboard.

I’m currently learning Microsoft Azure and open to internships and entry-level roles in cloud, IT infrastructure, networking, and technical support.
